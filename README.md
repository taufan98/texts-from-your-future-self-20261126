A program that writes one funny text message from your future self to `/output/entry.txt` for the Texts From Your Future Self bounty on make.fun.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
cat out/entry.txt
```
